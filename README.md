# Data Cleaning & Reporting Automation

## Project Objective

This project automates data cleaning and reporting workflows using Python and Power BI.

## Dataset Used

Salary dataset containing:

* Age
* Gender
* Education Level
* Job Title
* Years of Experience
* Salary

## Tools Used

* Python
* Pandas
* Matplotlib
* Power BI

## Features Implemented

* Handled missing values
* Removed duplicate records
* Cleaned inconsistent text formatting
* Generated automated summary reports
* Created automated visual charts
* Built interactive Power BI dashboard

## Output Files

* cleaned_data.csv
* summary_report.csv
* dashboard.pbix
* chart images

## Outcome

Successfully automated data preprocessing and reporting workflows, improving efficiency and data quality.
